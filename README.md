# Fazaa-app-manua

منصة **فزعة FAZAAH** تربط العملاء بالمهنيين ومقدمي الخدمات في اليمن من خلال تجربة عربية متجاوبة.

## ما يحتويه المشروع

- واجهة React + Vite + TailwindCSS باللغة العربية واتجاه RTL.
- تسجيل العملاء ومقدمي الخدمات برقم الهاتف.
- رمز تحقق يظهر داخل شاشة التسجيل عند عدم ربط مزود SMS.
- صفحات الخدمات والمهنيين والطلبات والملف الشخصي.
- لوحات الإدارة ومقدم الخدمة.
- خادم Express ومسارات API للمصادقة والتخزين وWebDev.
- اختبارات Vitest لمسارات المصادقة وتسجيل الهاتف.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

يفتح الخادم على المنفذ `3000` افتراضيًا. يمكن تحديد منفذ آخر عبر `PORT`.

## الفحص والبناء والاختبارات

```bash
pnpm check
pnpm build
pnpm test
```

## تسجيل الهاتف ورمز التطوير

في بيئة التطوير/المعاينة، ينشئ الخادم رمزاً عشوائياً من 6 أرقام ويعرضه داخل شاشة التحقق نفسها. لا يوجد رمز ثابت مثل `123456`، ولا تُرسل رسالة SMS حالياً؛ الرمز المعروض مخصص للاختبار فقط.

في النسخة المنشورة الحالية فُعّل `PHONE_AUTH_EXPOSE_OTP=true` مؤقتاً بطلب المستخدم، ليعيد API رمز الاختبار وتعرضه شاشة التحقق نفسها. لا تُرسل رسالة SMS فعلية. هذا الوضع مخصص للحسابات والبيانات التجريبية فقط؛ فالرمز المعاد عبر API يتيح إكمال تسجيل الدخول. لا تستخدم أرقاماً أو حسابات أو بيانات حقيقية، وأزل هذا المتغير واربط مزود SMS قبل الاستخدام الحقيقي.

## متغيرات البيئة

لا تضع الأسرار داخل GitHub. خزّن `NEON_DATABASE_URL` (أو `DATABASE_URL` كاسم توافق بديل) ومتغيرات OAuth وغيرها كأسرار في بيئة التشغيل، وأضف إعدادات مزود SMS عند ربطه لاحقاً.

## بنية المشروع

```text
client/       واجهة React وصفحات التطبيق
server/       خادم Express ومسارات API
server/phoneAuth.ts  تسجيل الهاتف ورمز التحقق
client/src/lib/api-client-react/  عميل API المولد
shared/       الأنواع والثوابت المشتركة
drizzle/      مخطط قاعدة البيانات والترحيلات
```
